### README

This is a personal portfolio website written from scratch in HTML, CSS and JS with assets made in Figma.

The following pens of CodePen were used for the project cards, background effect and profile timeline respectively, each with their own modifications.

- **Shape Wave** by *Stijn Van Minnebruggen*: https://codepen.io/donotfold/pen/yyapzOP
- **Parallax Depth Cards** by *Andy Merskin*: https://codepen.io/andymerskin/pen/XNMWvQ
- **Single div timeline** by *Niels Voogt*: https://codepen.io/NielsVoogt/pen/MbMMxv/
